Station logbook

Nov 2026 — warden on duty

Last winter's bulletin server folded under the weekend rush: every skier hammered GET /bulletin?region=... and the caches choked on query strings. This season we moved everything to the shiny new HTTP QUERY method. You send what you want in the body, and our edge cache normalizes and stores it. Fast, even in a whiteout.

The summit has been closed to the public since the slide last March. Only the internal auditor reads its bulletin; it re-checks the summit every few seconds, bypassing the cache, so the readings are always fresh.

Note to self: the edge filter keeps nosy hikers away from the summit data. Nothing to worry about.
